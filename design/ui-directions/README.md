# SpeakMore 视觉方向预览

三个可切换方案：A 极简黑白、B 雾蓝银灰、C 石墨深色。

用户已选择 A「极简黑白」。生产界面据此采用白色内容区、中性浅灰导航、黑色主动作和轻量分隔；保留已有深浅主题设置，深色使用对应中性灰阶。独立预览继续保留三个方案用于对照，示例内容不会进入产品。

打开 `SpeakMore-visual-directions.html` 即可独立预览，无需安装依赖或启动服务器。开发预览地址为 `http://127.0.0.1:1420/design/ui-directions/index.html`，需要项目 Vite 开发服务运行。

可交互范围：方案切换、概览/设置切换、录音状态动画、识别语言与模型选择、设置开关、示例结果详情。所有内容均为内存中的设计演示，不调用麦克风、模型、剪贴板或系统设置。其他导航仅展示视觉效果。

使用项目既有 shadcn/ui Button、Switch 与 D 标识组件，图标使用 React Icons，过渡使用 Motion。主题仅作用于独立预览，没有修改生产界面。

视觉约束：保留系统中文字体；主标题 30px、正文 12–14px、辅助文字 10–12px；左对齐；通过区域留白和文字层级减少卡片与页脚装饰。A 以黑白对比为主，B 使用银灰与雾蓝，C 用石墨灰的明暗区分区域。

构建：`npx vite build --config design/ui-directions/vite.config.ts`。`built/` 是独立构建产物，单文件 HTML 将该产物的脚本与样式内联。

检查：独立 Vite 构建通过；开发预览检查了三个主题、页面切换、录音状态演示与设置开关。浏览器的 file URL 策略阻止了直接加载单文件 HTML；未声称该路径已做浏览器运行验证。
