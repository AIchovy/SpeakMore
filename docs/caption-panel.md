# macOS 字幕悬浮窗

2026-10-01：字幕可见内容从普通 Tauri 置顶窗口迁移到独立的非激活 NSPanel。隐藏的 Tauri 宿主保留 WebView、窗口标签和 IPC 生命周期；不改变 Tauri 窗口的 Objective-C 类。退出时先把内容视图归还宿主，再由 Tauri 销毁窗口。

面板设置 CanJoinAllSpaces、FullScreenAuxiliary、CanJoinAllApplications、Stationary 和 IgnoresCycle：同一字幕面板加入各个桌面 Space 和其他应用的全屏 Space，避免激活 SpeakMore 或把用户切回主窗口所在桌面。使用浮动窗口层级，切换前台应用时不隐藏，不成为主窗口或键盘焦点窗口。

拖动、外观调整、鼠标穿透和显示／隐藏统一通过原生面板执行，不再操作隐藏的宿主。字幕窗口的隐藏按钮继续转录，实时字幕页的「显示字幕」可以恢复面板；关闭按钮仍结束字幕。首次显示依据鼠标所在屏幕的 AppKit 可见范围定位，后续保留拖动位置。

验证：macOS 原生代码检查、前端构建及 7 项现有会议／字幕语言和错误显示检查通过。新版应用构建、签名及原生音频库校验通过。未启动真实录音或替用户切换当前桌面／全屏应用。人工验收：开始字幕后切换两个桌面，再进入其他应用全屏；检查字幕可见、可拖动、暂停与关闭正常，隐藏后转录继续并可恢复。开启鼠标穿透后从实时字幕页关闭穿透。
