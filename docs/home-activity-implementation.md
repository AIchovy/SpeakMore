# 首页使用足迹（2026-10-05）

首页提供近半年使用热力图、本周／近 30 天／全部记录统计，以及最近听写、会议和字幕入口。听写区收紧，保留开始／完成／取消和五分钟边界提示；听写设置折叠，开始会议与实时字幕可以直接进入。

## 交互与统计口径

- 热力图可按全部、听写、会议、字幕切换；点击日期，统计与可回看的记录切到当天；可以返回最近活动，未来日期不可选择。
- 展示听写字数、开口次数和录音时长；会议数量和录音时长；字幕使用次数和有效收音时长。另显示本周使用天数、连续使用天数，不估算节省时间，不设置中断惩罚。
- 字数只计算原始转写中的文字和数字，不含空白与标点，AI 整理不会重复增加字数或次数。
- 听写统计与历史内容保存分开：关闭历史或清空历史不会删除已累计的使用元数据。最近文字仅来自用户保留的历史及现有临时结果；长期保存的记录使用转写详情，临时结果仍有十五分钟说明。
- 会议目前按现存有效录音记录计算，续录仍为一场；未录到音频的权限失败记录不计入。删除会议会影响对应统计，导入的有效录音也计入。
- 字幕从此版本开始记录使用元数据，扣除暂停收音时间；为听写暂停后自动恢复仍算一次。记录包含时间、模式、是否开启翻译、是否保存，不额外保存字幕正文。已删除字幕档案不会再展示回看链接。
- 热力图使用本地开始日期，一次跨午夜录音归于开始当天。旧版只恢复仍可读取的听写次数、原文字数和时长；无法恢复的字数显示缺失说明，旧版字幕不补造数据。
- 数据加载失败显示暂不可用及重试，保留听写入口；首次使用显示真实零值和行动提示。

## 实现

SQLite v9 新增 `activity_events`，迁移沿用现有升级备份机制。听写首次结果入库时，同事务写入元数据；字幕结束或让出收音时，通过数据库 actor 写入累积时长。会议记录与已保存字幕档案在后台读取。`overview_activity` 只允许主窗口调用，返回完整每日聚合和最多五条每类近期记录，可指定本地日期。

首页监听听写结果、会议变化、字幕统计、历史设置和窗口恢复；会议频繁状态通知限频刷新。请求用代次检查忽略过期响应，切换日期时不暂时展示上一天内容。会议入口打开创建表单，不立即申请收音；会议记录链接定位来源；已保存字幕链接加载档案，运行中的字幕不会被自动结束。
