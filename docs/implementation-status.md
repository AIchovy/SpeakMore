## 2026-09-14 真实 ASR 检查点

新增 `crates/asr-worker`，通过真实子进程 stdio 管道验证，不使用转写替身：

- ASR/VAD 文件在解析前校验精确大小、SHA-256、绝对路径与普通文件类型。三份实际产物的固定仓库 revision、大小和上游 LFS 哈希已记录到 `resources/model-sources.lock.json`，实际下载逐一匹配；这是未签名来源记录，尚不具备生产清单的信任资格。
- small-q5_1、large-v3-turbo-q5_0 均成功加载并转写。VAD 使用 Silero 6.2.0 的 885,098 字节 ggml 模型，其实际 tensor 为 6 个 f16 与 9 个 f32；与 sys 0.15.0 的 whisper.cpp 1.8.3 组合通过当前 fixture 验证。
- 每次任务新建 WhisperState，greedy/temperature 0、最多 8 线程、auto/zh/en 配置、不翻译。VAD 只取首尾范围并各加 200 ms，保留内部停顿；不把 5 分钟任务切成多次产品结果。词典按实际 tokenizer 整词试装至 128 tokens，返回使用/省略数量。

## 2026-09-14 音频采集与 5 分钟检查点

新增 `crates/audio`，把设备输入、实时回调与 DSP 实现为可供桌面会话控制器接入的模块：

- 锁定 cpal 0.18.2、rubato 0.16.2、ringbuf 0.4.8。工作区各 crate 统一声明 Rust 1.91，实际编译器 1.91.1。cpal 使用公开设备 ID 接口；名称只用于显示。默认设备在开始时解析为具体 ID，显式选定设备断开时不能静默回退。
- 协商设备实际 8–192 kHz、1–8 声道、f32/i16/u16；采集回调归一化、限制振幅并写入预分配的 2 秒 ring。非有限值、非完整 frame、溢出及连续性错误使本次失败。应用回调内没有日志、文件、锁或分配；分配计数 test 覆盖全部三个采样类型，不代表第三方库/OS 内部实现也已证明无分配。
- 独立 owner 线程持有原生流与 DSP，UI 仅发送原子停止/取消信号和读取有界事件队列。先关闭流、排空并校验完整 frame 数，再交付一个结果；取消丢弃 PCM。准备期间取消会在慢速设备调用返回后复核，禁止迟到开启麦克风。cpal 的构建 timeout 并非所有后端都保证遵守，尚须原生权限、设备卡死与取消真机验收。
- DSP 在回调外预留最多 4,800,000 个输出样本；显式平均/选定通道、带滤波转为 16 kHz mono。单调时钟与设备 frame 数独立约束 300 秒，最后一块正常裁切，不把时限结束误判为丢帧。任一上限触发均报告到时结束；已有数据错误不能被正常裁切掩盖。
- 发现并修复重采样首尾偏移：重复去掉 `output_delay()` 样本会丢掉开头并在尾部补出静音。当前保留已对齐输出，以首尾脉冲位置、幅度、抗混叠与实际 frame 对应长度共同回归；不能仅用总长度正确作为完整性证据。
- 桌面新增 `list_input_devices` / `set_input_device` 受限 commands，SQLite 保存设备 ID 与版本；拒绝过期版本、无效 ID、不可用或不支持的设备。音频/会话忙时禁止更换；将来开始录音与配置冻结仍需一起交给 SessionController actor 串行处理。
- 音频设置页加入真实设备选择和刷新，保留断开的选择、显示失败原因；浏览器预览明确禁用设备读取。页面、设计源稿及 HTML 均显示最长 5 分钟，免费与 Pro 一致；4:30 剩余提示、5:00 自动转写、一次长录音只计一次有效结果均已写入设计，HUD 尚未接入，不能声称交互已实测。

## 2026-09-15 会话控制、模型使用与主窗口听写检查点
