## 使用入口

- 左侧「会议记录」：开始会议或导入录音；完成后查看决策、待办、关键数字与结论、下一步行动。
- 左侧「实时字幕」：选择系统声音、麦克风或两者；默认纯原文，可以打开翻译并选择目标语言。支持历史回看、暂留显示和回顾刚才。
- 设置 → 语音模型：下载会议转写、字幕识别、摘要与翻译所需模型。听写原有模型选择独立保留。
- 会议纪要与启用后的字幕翻译可跟随当前已配置的 AI 服务（详见末尾更新）；未选择服务时使用本地 Qwen3。音频始终在本机转写。可以显式选择全本地处理；失败不自动切换服务。

## 会议记录

已实现麦克风、系统声音、指定应用声音及系统声音＋麦克风，录音时显示两路电平。系统声音通过 ScreenCaptureKit，仅消费音频，不保存屏幕画面；采集应用范围为进程，浏览器不能精确限定单个标签页。建议使用耳机，尚无回声消除质量承诺。

会议录音持续到用户主动结束，不因会议时长自动停止，暂停不计入时长；主窗口、状态栏和菜单栏只显示累计时长。普通 Fn 听写仍为 5 分钟。录音控制可在页面和菜单栏操作，切换页面不停止录音。5 秒分片持续落盘，分别保存混合音频与可用的原始轨道；崩溃时保留已提交分片。系统睡眠、设备错误或音频积压会停止任务并保留可用内容，中断记录保留原因和漏录区间，点击「续录这场会议」继续使用原会议 ID、已提交音频和转写检查点。原应用范围按 bundle ID 恢复当前进程，也可调整音源后续录。

导入使用原生文件选择器及 AVFoundation，有界解码，文件上限 2 GiB；超过一小时需选择不超过 60 分钟的区间。源文件不修改。界面提供常见音频格式，实际可解码性由系统编码器决定，尚未逐个格式做完整验收。导出使用所选区间从零开始的会议时间轴。

会议可用已有 Whisper/SenseVoice 或新增 MOSS。模型缺失不会阻止先保存录音。长任务保存转写进度，重试从检查点继续。普通 ASR 时间戳约为 20–30 秒片段，MOSS 输出更细的片段时间戳和窗口内说话人分组。MOSS 每 60 秒处理，用 CAMPPlus 声音嵌入在本场会议内维护稳定身份和检查点；一次改名应用到关联片段，可以手动合并身份。短句、模糊匹配使用带窗口范围的「待确认」标签，不强制归人。暂不做跨会议声纹识别。

本地 Qwen3 提取四类事项，要求负责人/日期不明确时留空，输出带原文证据编号。原生校验结构、引用和长度，原文可回听。逐字稿、说话人、纪要、待办完成状态均可编辑，保存前归档旧版本，支持版本对比与恢复。重新整理不删除旧版本。支持复制、Markdown/JSON/TXT、待办 CSV、逐字稿 SRT/VTT 导出。

事实提取按文本预算分组，每组候选经过第二次 AI 核查；较小的候选集合进行全局合并，较大的集合保留分组条目。核查与提取使用同一所选文字模型或服务，不能视为独立模型或确定性的事实验证。未通过核查的条目保留并标为「依据待核对」，引用必须存在；合并改写后的条目重新进入待核对。尚无覆盖任意长内容的递归合并。AI 结果需要复核，不能据此宣称已达到设计中的准确率目标。

## 实时字幕

- 真正的 sherpa-onnx 流式识别，支持 Zipformer、Paraformer 中英文模型；不是循环调用离线听写接口。
- 部分识别结果持续更新，仅在启用翻译后把端点确认的原文送到所选文字服务或本地 Qwen3。以句子 ID 与原文匹配结果，丢弃迟到旧译文。
- 翻译队列有上限，过载明确提示；内存只保留最近 900 条字幕，避免持续运行无限积累。
- 独立黑白悬浮窗口，支持拖动、字号、透明度、原文显隐、鼠标穿透、暂停/停止；保持应用焦点。
- 所有实时字幕音源持续到用户主动结束，结束后可编辑原文或译文。点击粘贴后提示切到目标输入框，在原生层捕获并复核目标，一次性交付；不模拟回车发送。当前行为是确认交付时选择目标，而非录音开始时冻结输入框。
- 实时字幕不设置累计会议时长上限。默认不保存音频和字幕文件；可开启文字保存，按小时分卷，提供历史打开/删除及双语 TXT/SRT/VTT 导出。结束后当前文字暂留供复制与导出。
- 字幕运行时 Fn 听写会请求暂停并让出资源，听写结束后恢复；后台会议处理也支持给 Fn 听写让路并续跑。会议录音受保护，不被 Fn 中断。
- 会议和字幕可共享采集，避免同一来源重复启动系统录音。实际并行体验、资源占用和全屏多屏行为仍需真机验收。

音轨目前按单调时钟下的回调到达时刻近似对齐；尚未完成硬件 PTS 漂移校准。暂停时订阅者停止消费/写入，共享硬件可能仍为其他订阅者采集。字幕暂停时结束当前句并重建识别上下文，音源与翻译目标独立；原文/翻译模式跨重启记忆。显示器拔出自动位置回退尚未接入。

## Notion

使用内部连接密钥和已授权父页面 ID，密钥保存在 macOS Keychain。点击发送才传输文本，默认只包含纪要，可选择附带逐字稿，绝不上传音频。没有重复的隐私同意复选框，也没有后台联网自动补发。

发送时冻结纪要内容和修订，分批创建/追加；同版本重复发送返回原页面，编辑后创建新版本页面。写入前保存本地发送记录，遇到超时进入待核实状态。核实时比较远端每块的类型、文字和待办状态，避免仅凭块数量判断成功；远端已被改动时停止自动追加。无法确认唯一页面时请人工检查，不能盲目自动重建。

目前未用真实用户密钥连接 Notion。内部连接权限、真实网络失败恢复、限流仍需人工验证；公众 OAuth 不在本期实现范围。限流会保留任务并提示重试，尚未实现自动遵循 Retry-After 的重试调度。

## 本地存储和模型

应用数据根：`~/Library/Application Support/com.speakmore.desktop/`。

| 内容                              | 相对目录                         |
| --------------------------------- | -------------------------------- |
| 会议 manifest、音频分片、修订归档 | `meetings/{id}/`                 |
| Qwen3 4B Q4_K_M（约 2.5 GB）      | `models/meeting-text/`           |
| Zipformer（约 0.20 GB）           | `models/meeting-asr/zipformer/`  |
| Paraformer（约 0.24 GB）          | `models/meeting-asr/paraformer/` |
| MOSS（约 1.83 GB）                | `models/meeting-asr/moss/`       |

会议私有目录 0700，文件按私有文件创建。新增会议默认音频保留 7 天，可改不保留/30 天/一直保留；只清理已完成会议的音频，不删除未完成任务或纪要。旧会议保持原有保留行为，避免升级后意外删除。保留期在启动、任务结束和修改设置时检查，应用关闭时不运行后台清理。

新模型使用应用内固定 revision、文件大小和 SHA-256；下载与加载前校验。它们使用独立编译内置目录，尚未并入原有签名模型目录，也尚未提供新模型离线包导入、批量一键准备和完整能力描述字段。断网可运行已经安装的模型；应用不自动下载所有权重。

MOSS 使用应用按需安装的 Python 3.12.11 与固定依赖，优先 MPS、否则 CPU；不依赖用户系统 Python，不执行远端模型代码。运行环境和模型权重分别按需下载，Python 不包含于正式安装包。MOSS CPU 性能较慢；建议 16 GB 以上 Apple Silicon，尚未形成低内存机型支持结论。

数据目前以原子 JSON manifest/修订文件存储，尚未改为 SQLite 会议索引和分页。录音和读取不设一小时总样本上限，单次 PCM 写入、读取及 manifest 大小保护仍保留。已有基础隐私隔离不等于应用层加密、组织审计或行业认证，后者保留为后续组织版本范围。

## 构建与依赖复现

macOS 14+ Apple Silicon；需要现有项目的 Rust、Node、Xcode Command Line Tools 及 `uv`。

运行时源码和依赖版本：

- llama.cpp：`c85b92c69c955961621193cd51da194f3cbcedf3`。
- sherpa-onnx：沿用项目固定的 1.13.8 构建。
- MOSS 源码：`61bc29cd4120be7b5d3b761b64cd5dff57263642`。
- MOSS Python 依赖：[moss-runtime.lock.txt](../resources/moss-runtime.lock.txt)。
- 模型产物：[meeting-models.lock.json](../resources/meeting-models.lock.json)，Qwen 固定常量见 `src-tauri/src/meetings/text.rs`。

基础应用不再携带 Python、PyTorch 等 MOSS 运行依赖，也不要求构建机器安装 MOSS Python。构建脚本只复制 `resources/moss-package/` 中固定版本的接入代码（约 268 KB），并清理旧版生成目录中的 `moss-python/`。

```sh
npm run desktop:build
```

用户在会议模型选择中选择 MOSS 后，可点击“下载并安装 MOSS”；设置 → 语音模型也提供下载入口。首次安装先下载约 279 MB 运行依赖，再下载约 1.83 GB 模型权重。已有权重的用户可单独安装环境。依赖解压后约 1 GB，存放于应用数据目录 `runtimes/moss/moss-macos-arm64-v1/`，不写入系统 Python。

- `resources/moss-runtime-downloads.lock.json` 固定独立 CPython 3.12.11 及 64 个 macOS ARM64 / Python 3.12 wheels 的下载地址、大小和 SHA-256；不在用户机器运行在线 pip 解析或源码构建。
- 仅从固定官方 HTTPS 域名下载，逐文件校验，再在暂存目录离线安装；离线导入检查成功后才原子发布“已安装”状态。
- 下载和安装都支持取消。失败不标为就绪；重试复用已验证的完整下载文件，成功后删除下载缓存。崩溃遗留的暂存目录在下次安装时清理。
- 设置支持单独移除环境；会议处理期间禁止移除。模型权重、录音和纪要不会随环境移除。缺失环境会明确提示安装，不再要求重新下载“完整版应用”。
- 固定依赖列表可由 `scripts/runtime/lock-moss-downloads.py` 更新，更新后需验证真实离线安装。小型 MOSS 包的来源和许可见 `resources/moss-package/README.md`。

构建仍生成 Swift 系统音频库、流式识别库和本地文本工作进程。发行包会检查不包含 `workers/moss-python/`，避免回归为大包。正式发行仍需开发者签名、公证和发行许可检查；本地开发包使用 ad-hoc 签名。

## 更新：统一复用 AI 服务（2026-09-30）

听写整理、写作格式、会议纪要和字幕翻译共用「设置 → AI 服务」里保存的服务地址、模型和 Keychain 凭据。支持现有 OpenAI、Anthropic、Ollama 及 OpenAI 兼容协议，不局限于某个服务商，不要求重复配置密钥。

新会议和字幕默认「跟随当前 AI 服务」。选好并测试当前服务后可直接使用；没有当前服务时使用本地 Qwen3。功能页仍允许单独选本地 Qwen3 或另一个已配置服务。已有会议和显式保存的本地选择保持原样，避免升级后将历史内容自动转发；历史会议可在详情页选择「跟随当前 AI 服务」，点击重新整理后生效。用户主动选择外部服务时，输入框附近显示真实服务地址与文字发送位置；不新增同意复选框。

任务使用各自提示词和预算：听写遵循现有格式与文字保护规则，预算仍为 2.5 秒；会议按组提取并校验结构和证据，单请求预算 120 秒；字幕只翻译已确认短句，单请求预算 8 秒，等待队列有界。显式连接测试为 15 秒。某个模型通过连接测试不代表长会议或实时翻译质量、延迟已获保证。

音频识别仍使用本机 ASR，AI 服务只收到相应转写文字。选择外部服务后无需下载 Qwen3；选择本地处理时仍可离线运行。字幕开始时确定本次服务，听写抢占后恢复同一选择；运行中可以显式修改服务，使用代次标记丢弃旧服务的迟到结果。语音模型设置与文字服务配置职责独立。

已有完整逐字稿可以直接重新生成纪要，不重新加载 ASR；即使保留期已清理音频也可继续整理。服务失败保留原文和旧纪要，不自动换服务重试。外部服务遵循全局云端开关，关闭后取消进行中的文字处理；已经发送的请求无法撤回。字幕翻译失败单独提示并重试，识别与原文显示继续，不自动切换服务；关闭翻译会丢弃迟到译文。

本次验证：27 项 provider 测试通过，包含四种协议的字幕请求、会议 JSON、取消、云端限制及原听写行为；3 项默认选择/旧数据迁移/JSON 校验测试、4 项原服务界面测试通过；TypeScript/Vite 与原生构建通过。网络测试使用本机模拟服务，没有读取用户 API Key 或调用真实 AI 账户。真实服务的质量、额度、网络与字幕延迟由用户配置后验收。

### 可信度与更新规则

- 新纪要增加 `status`、`recipient`、`support`。提取后用同一所选模型或服务进行第二次核查，核对文本、负责人、日期、金额、否定和条件；引用校验限定在实际提供的原文组。核查不能凭空增加证据，也不能静默删除未通过的候选。没有匹配核查结果时标为待核对，用户可阅读证据后手动确认。
- 合并改写后的条目保持待核对。复制与 Markdown/TXT 导出也保留提议、承诺和待核对标记，个人补充单独成节。复制个人结果卡保留完成状态和过时提示；CSV 和日历提醒也携带依据状态，避免转交后丢失核对信息。旧记录缺少新字段仍能读取，不批量重写用户历史。
- 手动编辑记录原始文本，重新整理时保留修改、负责人、日期和完成状态；匹配不只依赖共享证据，避免一个片段中的其他任务被误删。
- 结果卡与会议 AI 回答记录原文摘录；再次查看时原文被修改或删除会标为可能过时。引用存在校验不等于每条结论在语义上得到保证，关键结论仍应点击原文核对。
- 个人笔记与模板要求维护独立修订进度。生成期间新增、修改或删除笔记不会被一次旧结果误标为已处理；局部更新也不会将未纳入的个人关注点误标为已完成整场整理。并发原文修改导致引用版本变化时拒绝提交迟到结果。
- 字幕翻译携带前四条已定稿上下文和相关纠错术语，只输出当前句译文。检测阿拉伯数字 token 不一致时提示核对，原文继续；日期、否定和中英混说约束由提示要求处理，不宣称已具备确定性语义核验。
