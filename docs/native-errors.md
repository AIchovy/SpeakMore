# 原生错误提示与语言切换

本次补齐常见原生错误的中英文展示，不改变录音、模型校验、用量或自动输入资格。单次录音仍为 300 秒，本期不限每日次数。

## 展示合同

原生端使用 `AppError { code, userMessage, retryable }`。前端在 `src/lib/errors.ts` 集中处理固定错误代码，包括通用错误、麦克风、worker、模型下载与导入、快捷键、剪贴板、会话存储、AI 服务、系统凭据和数据库启动。

- 英文使用固定代码映射，给出对应处理步骤，不匹配中文正文。
- 已知代码的中文保留原生提供的用户说明；该字段必须是经整理的用户消息，不能传入底层异常、路径、HTTP body 或密钥。
- 页面、表单和历史加载状态保存结构化错误，渲染时选择当前语言。切换语言后，仍保留的错误也按新语言显示。
- 未知代码、旧字符串、意外异常及原型继承的代码使用通用提示；不调用原始异常的 `toString`，也不直接显示 `Error.message`。
- 原生 `retryable` 保持不变。文案不会授予开始、复制、模型使用或自动输入资格。
- 模型行保留既有固定错误类型，展示时进入同一映射。准备状态继续使用独立的 `readinessCode` / `readinessDetailCode`。

快捷键绑定错误、服务错误和录音条完成提示不再提前折叠成中文字符串。录音条存在结果时清除旧错误，只表示结果已生成，不表示已经粘贴；取消和八秒通知生命周期保持不变。

词典编辑器显式记录触发按钮，关闭后返回该按钮；首次添加使空状态按钮消失时，退回页面上的添加按钮。取消编辑清除该表单错误，避免已经放弃的失败继续显示为页面级警告；关闭按钮辅助文字跟随界面语言。

## 存储警告优先级

会话存储警告区分 `HistoryNotSaved`、`LocalCleanupIncomplete`、`UsageNotSaved`、`RefinementNotSaved`、`DeliveryStatusNotSaved` 和 `DeliveryReceiptNotSaved`。

`UsageNotSaved` 必须保留优先级：用量保存失败后，后续润色或交付回执的写入错误不能覆盖它。已有结果仍可在临时结果中复制；不因使用统计失败封锁后续听写；配置或隐私策略无法读取时仍受原生存储检查保护。此前不同存储错误共用文本槽位，后发生的错误会隐藏这一原因，现已修复。新的成功处理可以正常刷新警告，不能由页面语言切换清除。

## 页面进入动画

独立原生验证中，后台窗口的页面辅助功能树已完整生成，但主内容仍保持初始透明状态。页面进入动画改为从 4 px 位移恢复，不再把整页初始透明度设为零；内容无需等待动画帧才能阅读。该修改不代替前后台、减少动态效果、多屏及辅助技术矩阵的正式验收。

## 未放行范围

`InvalidInput` 的英文仍是通用检查说明，并非所有字段都已有独立错误码。后续 [原生语言检查](./native-language.md) 补齐了首次配置、应用自有菜单切换，以及此处曾观察到的 Select 关闭残留和保存后焦点恢复。真实设备/Keychain/网络故障、全部录音菜单状态、长文案截断、200% 缩放、VoiceOver、完整焦点与物理快捷键仍需专项验收。原生窗口的实际验证结果另记于 [实现状态](./implementation-status.md)。
