# SenseVoice 桌面会话与资源验证

2026-09-16。256 行候选已通过真实桌面会话链路验证：本地导入、SQLite 登记与重开、保存选择、连续三次完整 300 秒转写、取消、版本/家族切换、损坏文件拒绝和单独卸载。**本轮测量范围是桌面会话测试宿主与它的 worker，不包含 WebView；整应用资源 Gate 仍未通过。**

候选使用 `sensevoice-tiled256-v1`，模型 SHA-256 为 `46346d31c9314b4873aa16882f20955774cda4048a849c80db2a27117569a3d8`。测试版本的安装身份为 `sensevoice-small-int8--449f53e709f54de54d48c2bbfa225bd5d2f69e9ad620f78c946cd69de9dc16d2`，与上一轮 worker 检查相同。模型权重、原 VAD、tokens 与 300 秒限制没有改变。

## 实际覆盖范围

使用产品 `ModelManager`、`SqliteModels`、桌面会话 actor 和当前 macOS 包内的两个 release CPU worker。临时目录从空库开始，模型经产品的本地导入接口复制、验证和登记；候选目录用测试专属的签名信任，不读取生产密钥，也不修改生产目录。可下载模型仍为原有三项。

只有采集源被替换：先校验公开英语 WAV 的摘要，再构造 16 kHz mono f32 音频。完整输入包含 4,800,000 个样本，保持内部停顿。队列将 PCM 所有权移给采集事件和产品处理链路，不额外保留整段 fixture 副本。它验证完整音频传输与推理，**不验证真实麦克风、重采样、墙钟五分钟上限或权限行为**。

三次英语使用产品默认的 **auto 语言**，文本各 2,699 UTF-8 bytes，SHA-256 为 `9079ae94ae1a96a6ea61362836534b2cb192f93754e5d31e37ddd994c6a91275`。上一轮 worker 对照使用显式 en，输入配置不同；不能把两组摘要差异当成相同配置的输出变化。重复公开片语只用于接线、稳定性和资源检查，不计入自然语料准确率。

## 资源测量

本机为 Apple M4（Mac16,1）、32 GiB、macOS 15.6.1。会话宿主为 debug 测试二进制，worker 为已有 release 应用包中的真实产物；测试没有替换或重建正常应用包。完整检查约 343 秒，并非设计要求的连续 30 分钟实机使用。

独立采样器使用 Xcode SDK 的 `proc_bsdinfo` / `rusage_info_v4`，只枚举指定测试 PID 的子树。每次读取前后复核进程启动标识与父 PID。`proc_listchildpids` 返回 PID 数量，不能按 `proc_listpids` 的字节数解释；接口依据为 [Apple libproc 源码](https://github.com/apple-oss-distributions/xnu/blob/main/libsyscall/wrappers/libproc/libproc.c)。不读取窗口内容、进程内存正文或其他用户应用。

目标间隔 100 ms；实际最大采样间隔 123.369 ms，单次读取窗口中位数 3.4125 ms、最大 63.661 ms。共 3,350 次尝试，3,310 次完整，40 次在进程退出/重建阶段读数不完整，原始记录保留且不计入合计峰值。阶段标签按收到的测试日志归类，边界存在约一个采样周期的误差。

表中合计是**同一轮采样内各进程的当前值之和**，没有相加各进程独立的历史峰值。读取仍是先后执行的近同时观测，不是 OS 原子快照；短于采样间隔的分配可能遗漏。RSS 可能重复计算共享驻留页，physical footprint 单独列出，二者不能互换。

| 阶段              | ASR 时长  | 合计 RSS 采样峰值   | 合计 physical footprint 采样峰值 |
| ----------------- | --------- | ------------------- | -------------------------------- |
| 候选加载          | —         | 781,697,024 bytes   | 285,755,096 bytes                |
| 第一次完整 300 秒 | 33.330 秒 | 1,305,083,904 bytes | 1,066,174,672 bytes              |
| 第二次完整 300 秒 | 33.039 秒 | 1,208,729,600 bytes | 1,197,164,800 bytes              |
| 第三次完整 300 秒 | 32.906 秒 | 1,163,640,832 bytes | 1,176,193,280 bytes              |

全序列合计 RSS 的最高采样值为 **1,305,083,904 bytes / 1.215 GiB**，合计 footprint 最高为 **1,197,164,800 bytes / 1.115 GiB**。会话测试宿主本身最高 RSS 为 42,074,112 bytes / 40.125 MiB，最高 footprint 为 31,621,816 bytes。所有完整采样中最多有一个 worker；不完整样本不能用于证明进程数量或内存上限。没有控制系统负载、压缩或温度，不据此发布 P95 或最低机型承诺。

## 复现与证据

```sh
python3 scripts/diagnostics/sensevoice-actor-memory.py .cache/sensevoice/graph-study/tiled-e0zkpzmp/report.json
```

本次原始目录为 `run-93g1m21a`。[结构化证据](./evidence/sensevoice-tiled-actor-2026-09-16.json) 包含报告、文件摘要和结束后回收检查；[压缩原始采样](./evidence/sensevoice-tiled-actor-2026-09-16.samples.jsonl.gz) 保留全部 3,350 次尝试。专项集成测试通过；桌面 all-targets Clippy（session-fixtures/target-audit，`-D warnings`）、Rust fmt、Python 语法和 C `-Wall -Wextra -Werror` 检查通过。
